Portfolio Styleguide

OVERVIEW

Project Overview

This styleguide functions as both documentation and a working demonstration of the design system developed for a forthcoming portfolio refresh. While the full portfolio will showcase a broader range of work and pages, this document defines the design vocabulary and the modular blocks that will support the portfolio.

It is structured into three sections:

Type

Defines the typography system — which fonts are used, in which weights, and in what contexts.

Color

Documents the color palette, including primary, accents, neutral colors, their intended use cases, and accessibility contrast data.

Interface

Covers the structural design decisions that organize content visually across the portfolio. This includes layout, components, and spacing.

Future Design Goals

Future portfolio version will explore a more interactive landing page with full-bleed video elements.
