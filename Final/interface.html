INTERFACE

Interface System

This system covers much of the design not defined by typography or color. For the purposes of this project, it begins to define common and reusable elements for building portions of my portfolio.

The different elements reuse some of the same design vocabulary to maintain consistency. For example, soft corner radii, thicker card dividers, and iconography.

Iconography

This system uses the Google Material Design icon system. It has proven to be a versatile collection that works across sizes and has a large breadth of options. From testing against the Bootstrap Icon library, I found it to pair better with the overall aesthetic of the page, particularly with the typography system.

Responsive Design

Additionally, this style guide was built upon Bootstrap to provide a great deal of responsive design support. At the same time, it was heavily styled from stock Bootstrap to avoid the recognizable appearance of Bootstrap-powered sites.

Corner Radius

Style: Soft

Value: 4px

Use: All buttons, inputs, and cards

Buttons

Style: Outlined

Value: 1px

Use: Border only, no fill.

Cards

Style: Bordered

Value: 1px

Use: All card elements, including swatches

Dividers

Style: Narrow, Medium-weight

Value: 3px

Use: Three variations are available — Default (Orange), Yellow, and Heavy (Black)
